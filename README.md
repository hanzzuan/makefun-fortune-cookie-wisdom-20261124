One original fortune-cookie line for a software developer, written by a small
Python program for the
[Fortune Cookie Wisdom for Developers](https://make.fun/bounty/u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44)
bounty on make.fun.

## The line

> Your estimates are not wrong; they are prophecies the code has not yet agreed to keep.

## How it works

`main.py` writes that single line to `/output/entry.txt`. No network, no
randomness, no dependencies — the same line on every run.

Run it:

```sh
python3 -P -s main.py
```
